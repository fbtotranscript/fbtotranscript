# Facebook to Transcript

Free tool to turn public Facebook videos and Instagram Reels into text.

- Live: https://fbtotranscript.com
- Instagram Reels: https://fbtotranscript.com/instagram

Paste a public URL (or upload audio/video). Extract uses existing captions. AI transcribes a 15-minute clip when captions are missing. Export TXT, SRT, or VTT.

No signup. Public videos only. Not affiliated with Meta.
